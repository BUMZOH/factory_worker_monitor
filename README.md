# Worker Detection App

YOLOを使用してUSBカメラ映像から人物を検出し、
指定した作業エリア（ROI）内に人物がいるかを記録するアプリです。

Version 1では、リアルタイムの人物検出結果を画面表示しながら、
1秒ごとの検出結果をCSVへ保存し、確認用の映像をMP4へ保存します。

Version 1

## 主な機能

- USBカメラから映像を取得
- YOLOによる人物検出
- ROI1 / ROI2 の2つの作業エリアに対応
- ROIごとに人物の有無を判定
- 人物のバウンディングボックスを表示
- 人物の中心点を表示
- ROIを画面上に表示
- ROIごとの検出状態を画面表示
- 現在日時を画面および録画映像に表示
- 1秒ごとの検出結果をCSVへ保存
- 1秒に1フレームのMP4動画を保存
- MP4を1時間ごとに自動分割
- 既存MP4を上書きしない連番保存

## ファイル構成

基本的な構成例です。

```text
app/
├─ app.py
├─ run.bat
├─ yolov8n.pt
├─ csv/
└─ movie/
```

`csv` と `movie` フォルダは、存在しない場合はアプリ起動時に
自動的に作成されます。

## YOLOモデル

Version 1では以下のモデルファイルを使用します。

```text
yolov8n.pt
```

`yolov8n.pt` はGitリポジトリには含めません。
`.gitignore` で `*.pt` を除外しています。

初回セットアップ時に、Ultralyticsからモデルを取得してください。

仮想環境へ必要パッケージをインストールしたあと、
プロジェクトの `app` フォルダで次のコマンドを実行できます。

```bash
python -c "from ultralytics import YOLO; YOLO('yolov8n.pt')"
```

取得した `yolov8n.pt` は `app.py` と同じフォルダへ配置してください。

```text
app/
├─ app.py
├─ run.bat

```

Ultralytics YOLOおよび学習済みモデルの利用条件については、
Ultralytics公式のライセンス情報を確認してください。

## 起動方法

Pythonからアプリを起動します。

```bash
python app.py
```

起動するとUSBカメラの映像が表示され、YOLOによる人物検出が
開始されます。

## アプリの終了方法

**映像ウィンドウを選択した状態で `ESC` キーを押してください。**

`ESC` キーを押すとループを終了し、MP4ファイルとカメラを
正常に閉じてからアプリを終了します。

MP4ファイルを正常に確定させるためにも、通常の運用では
`ESC` キーによる終了を推奨します。

## ROIによる人物判定

人物検出では、YOLOが検出した人物のバウンディングボックスの
中心点を使用します。

中心点がROI内に入っている場合、そのROIを検出状態とします。

```text
人物の中心点がROI内
    ↓
DETECTED
    ↓
CSVには 1 を記録
```

人物がROI内にいない場合は `0` を記録します。

ROI1とROI2は個別に有効・無効を設定できます。

## CSV記録

CSVは `csv` フォルダへ保存されます。

ファイル名：

```text
worker_detection_YYYYMMDD.csv
```

例：

```text
worker_detection_20260912.csv
```

CSVは1日単位です。

記録項目：

```text
measure_at,roi1_result,roi2_result
```

記録例：

```csv
measure_at,roi1_result,roi2_result
2026-09-12 14:00:00,0,0
2026-09-12 14:00:01,1,0
2026-09-12 14:00:02,1,1
```

検出結果は約1秒ごとに記録されます。

## MP4記録

MP4は `movie` フォルダへ保存されます。

録画映像は1秒に1フレーム（1 fps）で記録します。

YOLOによる人物検出と画面表示自体は毎フレーム行うため、
リアルタイム画面は1 fpsにはなりません。

### 1時間ごとのファイル分割

MP4は時刻の1時間単位で自動的に分割します。

例：

```text
20260912_1400.mp4
20260912_1500.mp4
20260912_1600.mp4
```

`20260912_1400.mp4` は14時台の映像を記録するファイルです。

アプリを14:30に起動した場合でも、ファイル名は
`20260912_1400.mp4` になります。

15:00になると現在の動画ファイルを閉じ、
`20260912_1500.mp4` へ切り替えます。

## MP4の上書き防止

同じ時間帯のMP4がすでに存在する場合は上書きしません。

例：

```text
20260912_1400.mp4
20260912_1400_2.mp4
20260912_1400_3.mp4
```

同じ時間帯にアプリを再起動した場合でも、それまでの録画映像を
残したまま新しいファイルへ記録できます。

## タイムスタンプ

画面左下に現在日時を表示します。

例：

```text
2026-09-12 13:55:55
```

このタイムスタンプは画面表示だけではなく、MP4へ保存される
映像にも記録されます。

そのため、後からMP4だけを確認しても撮影日時を確認できます。

## 主な設定

ソースコード上部で主な設定を変更できます。

```python
CAMERA_NO = 0

CONFIDENCE = 0.5
IOU_THRESHOLD = 0.3

VIDEO_FPS = 1.0
```

ROIについてもソースコード上部で設定します。

```python
ROI1_ENABLE = True
ROI1_X1 = 150
ROI1_Y1 = 150
ROI1_X2 = 550
ROI1_Y2 = 450
```

ROI2も同様に設定できます。

## 保存データの役割

Version 1では、CSVとMP4の役割を分けています。

```text
CSV
└─ 人物検出結果の集計・分析用

MP4
└─ 実際の状況を後から確認するための映像記録
```

作業時間などの集計値そのものはアプリ内では計算せず、
CSVに保存された1秒ごとの検出結果から後で集計することを
想定しています。

## 異常終了について

通常終了時は `VideoWriter.release()` を実行してMP4を正常に
閉じます。

ただし、停電、OSの異常終了、強制的なプロセス終了などでは、
書き込み中のMP4が正常に確定されない可能性があります。

その影響範囲を小さくするため、Version 1ではMP4を
1時間ごとのファイルに分割しています。

CSVについては1回の記録ごとにファイルを開いて書き込み、
その都度閉じる方式です。

## Version 1の設計方針

Version 1では機能を複雑にしすぎず、

```text
人物を検出する
↓
ROIごとの状態を記録する
↓
CSVを残す
↓
確認用MP4を残す
```

という基本機能に絞っています。

設定のJSON化や記録データの集計・動画結合などは、
必要に応じて今後追加する想定です。
